# PSO Hitch Showcase

This sample exercises 384 real material/render-state combinations. Eight startup seed tiles keep the camera, presentation clock, and motion scene live; 376 tiles belong to a separate deferred `combat` trace phase and remain hidden until a mid-game content request.

Use **Tools > Shader Hitch Pipeline > Build PSO Showcase**, or run the repository-level `Tools/Invoke-PsoShowcase.ps1` workflow. A cache-isolated cold Player trains both phases; the matching final Player supplies Unity all-at-once and deadline-scheduled controls. At `CONTENT_REQUEST`, the control submits all 388 deferred graphics-state entries in one batch while the scheduler admits deadline/cost/hot-set batches. Both receive the same 1.50 s deadline, and content begins revealing even if a policy missed it.

The workload contains no artificial sleeps or simulated frame spikes. Two new states become visible per presentation at a 240 FPS target, so all modes request the same nominal 480 states/s without a showcase-only activation batch. The live scanline, presentation clock, and frame metrics are rendered by the Player; visual statistics reset exactly at `CONTENT_REQUEST`. Reports retain 1080 raw frames, every ≥8.33 ms presentation-budget miss, the complete deferred-phase receipt, and the `CONTENT_COMPLETE` marker. Keep the Windows Player visible and unobscured while capturing so D3D12 submits presentable frames.
